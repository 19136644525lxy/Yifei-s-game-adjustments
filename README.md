# Yifei's Game Adjustments

一个为Minecraft 1.20.1开发的Fabric模组，添加了多种游戏调整功能。

## 功能特性

- **物品系统** - 添加了硬化粗石系列工具
- **游戏机制调整** - 甘蔗骨粉、蛋糕掉落等功能
- **信息显示** - HUD显示FPS、TPS、MSPT、方向、生物群系等
- **缩放功能** - 游戏内视角缩放
- **输入法管理器** - 游戏内IM自动切换
- **配方系统** - 添加了多种自定义配方
- **配置界面** - 集成ModMenu配置

## 环境要求

- Minecraft 1.20.1
- Fabric Loader >= 0.18.4
- Fabric API
- Java >= 17
